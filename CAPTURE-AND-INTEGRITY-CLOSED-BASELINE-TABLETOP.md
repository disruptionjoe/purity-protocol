# Capture and Integrity Closed-Baseline Tabletop

Status: executed synthetic baseline; not a threat model validation, role,
gate, policy, invitation, or evidence of real-world resistance.

## Question

Can the current founder-only repository baseline make representative capture
and integrity failure paths visibly stop before they are mistaken for
authoritative effort, decision voice, or a safe future eligibility expansion?

## Construction and evidence boundary

This finite paper tabletop uses only fictional records and the current public
repository authority. It tests no person, account, contributor, participant,
incentive, funding mechanism, live service, private source, or real-world
behavior. A case is a pass only when the current record yields an explicit
closed-baseline stop or denial; it is not a pass on resistance to the threat.

The test reads `CONSTITUTION.md`, `DECISIONS.md`, `GOVERNANCE.md`, `STATUS.md`,
`AGENTS.md`, `LANES.yaml`, `LANE-STATE.yaml`, and
`FIRST-ELIGIBILITY-GATE-EVIDENCE-SPECIFICATION.md`. It treats all fictional
claims as constructions, not reports about real people or organizations.

## Result

All cases resolve to a closed-baseline denial or stop. The narrow result is
that current public authority does not supply a hidden route by which apparent
support, status, free work, a merge, a citation, sponsorship, or review delay
becomes project eligibility or governance authority. It is **Synthetic
support** only for making these failure paths legible before acceptance.

The tabletop is deliberately negative. It does not show that a future role can
resist sybils, collusion, capture, exclusion, hidden sponsorship, information
asymmetry, founder bottlenecks, or reviewer concentration. It establishes no
threshold, qualification method, detection method, mitigation, or safe level
of risk.

## Falsifiers and no-go evidence

This control would fail if any case could create authoritative effort, decision
voice, meta-governance voice, acceptance, or a gate-satisfaction inference
without a separately ratified authority path. It would also fail if a case
required private context or unwritten founder intent to resolve.

Neither occurred in the tested baseline. For any future candidate, an
unresolved identity, provenance, correction, authority, rights, consent, or
non-reversible-consequence state remains a no-go condition rather than a
mitigation opportunity.

## Disposition

Current disposition: **closed-baseline synthetic support; capture-and-integrity
bundle remains incomplete and the first eligibility gate remains not
decision-ready**.

The next testable work requires a separately predeclared candidate role,
rights/provenance boundary, and ethical/legal review scope. That boundary
belongs to Joe; this tabletop neither chooses nor requests it.
